# 🏥 MediCare – Hospital Management System

MediCare is a Java-based Hospital Management System developed using the MVC architecture to streamline hospital operations and improve communication between administrators, doctors, and patients. The application provides secure role-based access, enabling efficient management of appointments, doctor profiles, patient records, and hospital services.

The project is built using Java Servlets, JSP, JDBC, MySQL, Maven, and Apache Tomcat, following the Model-View-Controller (MVC) design pattern for better code organization, scalability, and maintainability.

## ✨ Features

* Secure User Authentication (Admin, Doctor & Patient)
* Patient Registration & Login
* Doctor Login & Profile Management
* Admin Dashboard
* Doctor Management (Add, Update & Delete)
* Specialist Management
* Appointment Booking & Scheduling
* Appointment Status Tracking
* Patient Record Management
* Password Management
* Role-Based Access Control
* CRUD Operations for Doctors, Specialists & Appointments

## 🛠️ Tech Stack

## 🏛️ Architecture

## 👥 User Roles

### 👨‍💼 Admin
- Secure Login
- Manage Doctors
- Manage Specialists
- View Patients
- View and Manage Appointments
- Monitor Hospital Operations

### 👨‍⚕️ Doctor
- Secure Login
- Update Profile
- Change Password
- View Assigned Appointments
- Update Appointment Status

### 🧑‍🤝‍🧑 Patient
- Register & Login
- Book Appointments
- View Appointment History
- Manage Account
- Change Password
